# Testing Methodology (Zero Bias, 100% Reproducible)

1. **Identical Prompt:** Every model receives the exact same prompt copy-pasted verbatim (default settings unless explicitly noted).
2. **Clean Context:** Fresh session for every run—no hidden chat history or warm-up hints.
3. **Raw Evidence Included:** Exact prompt, raw output/code, visual screenshot or 20s screen recording, runtime, and real estimated cost.
4. **Clear Evaluation Criteria:**
   - Strict adherence to instructions
   - Real tested quality (compiled/rendered, never guessed)
   - Bugs, hallucinations, or silent failures
   - Speed & real cost-to-quality ratio
